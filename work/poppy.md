# Poppy — Dog Mind Prototype Work Memory

> 역할: Poppy 프로젝트의 목표, 요구사항, 주요 결정, 구현/검증 상태, 다음 작업의 단일 원본.

## 1. 목표

반려견의 사진·짧은 영상을 입력받아 관찰 가능한 행동 신호와 상황 정보를 바탕으로 현재 감정/상태와 욕구·의도를 추정하는 웹 프로토타입을 만든다.

- 문자 그대로의 “마음 읽기”를 주장하지 않는다.
- 건강/의학 진단 기능은 범위에서 제외한다.
- 결과는 일반 보호자가 이해하기 쉬운 형태로 제공한다.
- 사용자에게는 개 의인화 한마디와 실제 분석을 분리해 보여준다.

## 2. 확정 요구사항

1. 입력은 사진과 짧은 영상이다.
2. 영상 최대 길이는 30초다.
3. 영상은 얼굴만이 아니라 귀, 눈, 입, 꼬리, 자세, 움직임, 상호작용 등 전신 행동을 분석한다.
4. 분석 결과는 감정/상태 + 현재 욕구/의도를 포함한다.
5. 신뢰도는 퍼센트가 아니라 `높음 / 보통 / 낮음`으로 표시한다.
6. 해석이 모호하면 억지로 하나를 고르지 않고 최대 2개의 대안 해석을 함께 제시한다.
7. 결과에는 짧은 근거와 보호자가 취할 수 있는 간단한 행동 조언을 포함한다.
8. 의학적 진단은 하지 않는다.
9. 결과 표현은 “강아지의 한마디(의인화)”와 “실제 분석”을 구분한다.
10. 근거는 현재 관찰 행동, 상황, 저장된 개별 특성, 일반 개 행동 지식, 품종 특성 등 출처 범주로 구분한다.
11. 기본 판단 우선순위는 현재 관찰 행동 > 개별 특성 > 현재 상황 > 일반 개 지식 > 품종 특성 > 과거 피드백이다.
12. 품종 특성은 보조 근거로만 사용한다.
13. 미등록/길거리 개도 분석할 수 있다.
14. 미등록 개는 품종을 추정하지 않고 일반 개 행동 + 현재 입력 + 상황만 사용한다.
15. 상황 입력은 미리 정한 선택지 + 짧은 자유 입력으로 받는다.
16. 사용자 피드백은 `맞는 것 같아요 / 아닌 것 같아요` 두 가지다.
17. 피드백은 향후 분석에 약하게 참고하며 별도 무거운 ML 학습 시스템은 만들지 않는다.
18. 분석 이력을 저장한다.
19. 계정 하나에 여러 강아지를 등록할 수 있다.
20. 한 번의 분석에서는 한 마리만 대상으로 한다.
21. 강아지 프로필 기본 필드는 이름, 나이/생년 정보, 품종, 성별, 중성화 여부, 평소 성격이다.
22. 개별 특성은 미리 정의된 선택지와 자유 텍스트를 함께 지원한다.
23. AI가 개별 특성을 제안할 수 있으나 사용자가 확인한 경우에만 저장한다.
24. 분석 지식은 검증된 사전 지식 DB + AI의 일반 해석을 조합한다. 매 분석마다 웹검색하지 않는다.
25. 초기 대상 사용자는 일반 반려견 보호자다.
26. 초기 제품 형태는 웹 앱이다.
27. 인증은 단순 ID/비밀번호 방식이며 소셜 로그인·이메일 인증은 초기 범위에서 제외한다.
28. 비밀번호는 평문 저장하지 않고 해시한다.
29. 업로드한 원본 미디어는 분석 후 삭제하고 분석 결과만 보관한다.
30. AI 분석 엔진은 OpenAI 멀티모달 모델을 사용한다.

## 3. 아키텍처 / 기술 결정

### 선택 확정

- 애플리케이션 구조: Next.js 단일 애플리케이션(monolith)
- 언어: TypeScript
- 데이터베이스: SQLite 로컬 파일
- ORM: Prisma
- 영상 처리: FFmpeg / ffprobe
- AI: OpenAI API
- 인증: 단순 세션 기반 ID/비밀번호 인증
- 초기 목표: 로컬에서 실제로 동작하는 프로토타입

### 구현 방향

- OpenAI에 영상을 직접 전달하지 않고 FFmpeg로 대표 프레임을 추출한 뒤 이미지 입력으로 전달한다.
- 현재 구현은 영상에서 최대 8개의 JPEG 프레임을 추출하는 방향이다.
- SQLite DB 파일은 `prisma/app.db`를 사용한다.
- 업로드 미디어는 임시 처리 후 삭제한다.
- OpenAI 응답은 구조화된 스키마로 파싱한다.

## 6. 현재 알려진 주의점

- Prisma 7.10.0 사용 중이며 CLI에서 Prisma 8 업데이트 알림이 표시됐으나, 프로토타입 검증 전에는 메이저 업그레이드를 진행하지 않는다.
- 설치 중 npm이 `@prisma/engines` install-script 관련 경고를 표시했으나 이후 Prisma Client 생성 및 migration은 실제로 성공했다.
- 품종 지식 DB는 아직 소수 품종의 초기 샘플 수준이므로 확장과 근거 보강이 필요하다.
- 로컬 SQLite는 현재 프로토타입에는 적합하지만 향후 공개 배포 시 파일 영속성/동시성 요구에 따라 DB 구조 재검토가 필요하다.
- 현재 구현 존재와 실제 end-to-end 작동 검증은 구분한다.
